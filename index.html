🔗 Conexión con OneDrive / Power Automate
¿Cómo funciona?
Cada registro se envía automáticamente a un flujo de Power Automate que escribe una fila en tu Excel de OneDrive. Todos los técnicos comparten el mismo archivo.
📋 Cómo configurar Power Automate
1
Abre Power Automate Ve a make.powerautomate.com con tu cuenta Microsoft 365.
2
Crea un flujo nuevo Clic en "Crear" → "Flujo de nube instantáneo" → selecciona el disparador:
"Cuando se recibe una solicitud HTTP"
3
Pega este esquema JSON en "Cuerpo JSON de solicitud":
{ "type": "object", "properties": { "fecha": {"type": "string"}, "hora": {"type": "string"}, "sticker": {"type": "string"}, "transformador": {"type": "string"}, "potencia": {"type": "number"}, "tipo": {"type": "string"}, "estado": {"type": "string"}, "latitud": {"type": "string"}, "longitud": {"type": "string"}, "precision_m": {"type": "string"}, "maps_link": {"type": "string"}, "tecnico": {"type": "string"}, "observaciones": {"type": "string"}, "tiene_foto": {"type": "string"} } }
4
Agrega una acción: "Agregar una fila a una tabla" Conector: Excel Online (Business)
Selecciona tu OneDrive, elige el archivo Excel y la tabla donde guardar los datos.
5
Copia la URL del webhook Guarda el flujo, copia la URL generada y pégala arriba en esta app.
💡 Tip: Crea primero el archivo Excel en OneDrive con una tabla que tenga estas columnas: Fecha, Hora, Sticker, Transformador, Potencia, Tipo, Estado, Latitud, Longitud, Precisión GPS, Google Maps, Técnico, Observaciones.
